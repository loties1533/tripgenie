# 👥 TripGenie — User Stories (Analyse Fonctionnelle)

Voici les récits utilisateurs qui ont guidé le développement de l'application.

---

## 🔐 Authentification & Profil
1.  **Inscription** : En tant que nouvel utilisateur, je veux créer un compte sécurisé afin de pouvoir sauvegarder et retrouver mes futurs projets de voyage.
2.  **Connexion** : En tant qu'utilisateur enregistré, je veux me connecter avec mon email/mot de passe afin d'accéder à mon tableau de bord personnel.
3.  **Profil** : En tant qu'utilisateur, je veux définir mes préférences globales (budget, type de voyage préféré) pour que l'IA me connaisse mieux.

## 🤖 Interaction & Onboarding
4.  **Chat Intelligent** : En tant que voyageur indécis, je veux discuter avec un assistant IA plutôt que de remplir un formulaire, afin de définir mon voyage de manière naturelle et fluide.
5.  **Analyse de Demande** : En tant qu'utilisateur, je veux que l'IA comprenne mes besoins implicites (ex: "je suis fatigué" -> mode Relax) pour recevoir des suggestions pertinentes.

## ✈️ Génération & Recherche (RAG)
6.  **Données Réelles** : En tant que voyageur exigeant, je veux que l'IA vérifie les vrais prix et les disponibilités actuelles sur le web afin d'éviter les "hallucinations" et les hôtels fermés.
7.  **Comparaison de Packs** : En tant qu'utilisateur, je veux recevoir trois options différentes (Relax, Adventure, Party) pour un même voyage afin d'avoir le choix de l'ambiance.

## 📊 Visualisation & Aide à la décision
8.  **Genie Score** : En tant que décideur, je veux voir une note sur 10 basée sur mes critères personnels pour savoir quel pack correspond objectivement le mieux à mon budget et mes envies.
9.  **Carte Interactive** : En tant qu'explorateur, je veux voir les étapes de mon voyage sur une carte interactive pour visualiser géographiquement mon itinéraire.

## 🗳️ Social & Validation
10. **Système de Vote** : En tant que planificateur, je veux pouvoir voter (pouce levé/baissé) sur les activités proposées afin d'affiner mon itinéraire final.
11. **Partage** : En tant qu'utilisateur, je veux pouvoir partager mon voyage via un lien public afin de recueillir l'avis de mes amis ou de ma famille.
