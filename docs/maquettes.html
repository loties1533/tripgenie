4. Notes de conception & Accessibilité

Critère Décision Justification
Couleurs Or (#c9a84c) + Encre (#1a1a2e) + Parchemin (#faf8f3) Palette luxe-voyage, contraste WCAG AA ≥ 4.5:1
Typographie Georgia (titres) + DM Sans (corps) Lisibilité corps 14px min, titres avec caractère
Responsive Tailwind CSS — breakpoints sm(640) / md(768) / lg(1024) Mobile-first, grille s'adapte de 1 à 3 colonnes
Accessibilité aria-label sur boutons, focus visible, roles ARIA Conformité RGAA — navigation clavier possible
Sécurité front Validation email côté client + serveur, sanitizeInput Protection XSS, entrées < 300 caractères
UX Chat Max 3 échanges, chips cliquables, auto-scroll Réduction friction, guidage progressif
