Fonctionnalités

Tout en une seule génération

Un pipeline IA orchestré côté serveur qui agrège vols réels, météo, hôtels et génère un pack structuré et scoré.

🤖

Onboarding conversationnel

L'IA pose des questions naturelles pour extraire destination, budget, dates et style. Pas de formulaire complexe.

🔍

Données temps réel

Vols, hôtels et événements recherchés via Tavily (web scraping IA) — pas d'hallucination sur les prix.

🎛️

5 modes de voyage

party · luxury · student · group · relax — chaque mode adapte le prompt, le scoring et le budget.

💬

Chat de modification

Modifie le pack après génération en langage naturel. Seule partie véritablement agentique du pipeline.

📊

Score déterministe 0–1

Algorithme pur sans IA. Pondération différente selon le mode. Même entrée = même score à chaque appel.

🔗

Partage & vote collectif

Lien public par voyage. En mode groupe, chaque membre vote pour construire un consensus.

Architecture

Pipeline IA orchestré

Les étapes sont prédéfinies et s'enchaînent toujours dans le même ordre. Ce n'est pas un agent autonome.

// POST /api/ai/generate │ ├─ 1. Validation Zod ← inputs validés avant tout │ ├─ 2. Promise.allSettled([ ← 5 recherches en parallèle │ smartFlightSearch(), ← Tavily : vols réels │ smartEventsSearch(), ← Tavily : événements locaux │ smartHotelSearch(), ← Tavily : hôtels │ getRealWeather(), ← OpenWeatherMap │ getDestinationPhoto() ← Unsplash (proxy backend) │ ]) │ ├─ 3. assemblePack() ← LLM + données réelles injectées │ Gemini → Claude → OpenRouter ← fallback automatique │ ├─ 4. scorepack() ← algorithme déterministe 0–1 │ └─ 5. Sauvegarde Supabase ← si utilisateur connecté

Stratégie de test

Tous les services externes sont mockés — les tests tournent sans aucune clé API.

  • Routes HTTP : auth, trips, votes, rate limiting, CORS
  • Flux end-to-end : génération complète, chat, photos
  • Scoring sur tous les modes (luxury, party, student…)
  • JWT : token absent, expiré, invalide, malformé
Sécurité

Défense en profondeur

Chaque vecteur d'attaque est adressé à son niveau optimal.

🍪

Cookie httpOnly

JWT inaccessible depuis JavaScript → XSS ne peut pas voler le token.

🔒

sameSite: strict

Cookie non envoyé sur requêtes cross-site → protection CSRF.

✅

Validation Zod

Chaque endpoint valide ses inputs avant tout traitement. Injection impossible.

🛡️

Isolation SQL

.eq('user_id', req.user.id) sur chaque requête. Aucun accès inter-utilisateurs.

⚡

Rate Limiting

10 req/h sur les routes IA, 100 req/15min global. Protection DDoS par IP.

🔑

Clés API côté serveur

Proxy backend pour Unsplash, variables d'env pour les LLM. Jamais dans le client.
